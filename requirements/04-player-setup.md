# 04 – Player Setup & Player Area

Source: Rulebook pp. 6–7.

## 1. Setup procedure (per player)

- **REQ-PS-01 Crew board.** Place the Crew board at the left of the player area. The player selects the **Basic** or **Advanced** side; opponents may use different sides.
  - The app should recommend Basic for the first few games and the first game with a new deck.
  - When the Basic side is used, the player keeps only **1** Mission Completion token; two are removed.
- **REQ-PS-02 Specialty markers.** Place the 3 Specialty markers on the zero space of each Specialty track (see [10-missions-and-specialties.md](10-missions-and-specialties.md)).
- **REQ-PS-03 Split the Crew deck** by the position indicator at the bottom of each card: Incident Deck, Deployed, Controlled Location, Development, Reserve, Available, Discard. The Captain card, and any Status card, has no indicator.
- **REQ-PS-04 Captain.** Place the Captain card right of the Crew board. The space above it is the **Duty Officer** space.
- **REQ-PS-05 Status card.** If present, place it above the Crew board.
- **REQ-PS-06 Draw deck.** Shuffle all **Available** cards facedown to form the Draw deck, placed below the Captain.
- **REQ-PS-07 Development pile.** Place all **Development** cards in a faceup pile above the Crew board. The player can inspect this pile at any time.
- **REQ-PS-08 Reserve deck.** Shuffle all **Reserve** cards into a facedown deck placed on top of the Development pile.
- **REQ-PS-09 Controlled Locations.** Place any **Controlled Location** cards faceup right of the Duty Officer space. This top row is the **Location Area**.
- **REQ-PS-10 Deployed cards.** Place any **Deployed** cards faceup right of the Captain. This middle row is the **Fleet Area**. For each deployed Ship, place its Ship token on the card.
- **REQ-PS-11 Incident deck cards.** Shuffle any cards marked **Incident Deck** into the central Incident deck. No Crew deck in this box has one, but the engine must support it.
- **REQ-PS-12 Discard pile.** Place any cards marked **Discard** faceup in the Discard pile at the far end of the Staging Area.
- **REQ-PS-13 Starting resources.** Each player takes 1 Dilithium, 1 Latinum and 1 Glory **from the supply**, not from the Stardate card.
- **REQ-PS-14 Away Teams.** Place the number of Away Team tokens shown on the Captain card onto the Captain. Each player uses a different colour.
  - If the number has a "+", the Crew deck's special rules say where the other tokens go.
- **REQ-PS-15 Opening hand.** Draw 5 cards. Five is the default **hand size**.
  - If an in-play card already modifies hand size, apply it now; the opening hand may differ from 5.
- **REQ-PS-16** The player with the Starting Player token takes the first turn.

## 2. Player area zones

The engine must track these zones per player:

| Zone | Visibility | Notes |
|---|---|---|
| Hand | Owner only | No hand limit |
| Draw deck ("your deck") | Hidden, ordered | "Your deck" always means the Draw deck unless another deck is named |
| Discard pile | Public | |
| Reserve deck | Hidden, ordered; the owner may view its contents, not its order (REQ-INF-05) | Source of enlisted cards |
| Development pile | Public | Enlisted by paying a development cost |
| Staging Area | Public | Bottom row. Cards played this turn |
| Fleet Area | Public | Middle row. Captain, deployed Ships and Ongoing cards |
| Location Area | Public | Top row. Duty Officer slot(s) and controlled Locations |
| Captain's Log | Public (click to view) | Under the Captain. See [11-logging-and-hidden-information.md](11-logging-and-hidden-information.md) |
| Crew board | Public | Specialty tracks, missions, turn summary |
| Status card | Public | Optional |
| Resource pool | Public | Dilithium, Latinum, Glory, Action tokens |

- **REQ-PS-20** "Your deck" means the Draw deck. Other decks, such as the Reserve deck or an opponent's deck, are always explicitly named.
