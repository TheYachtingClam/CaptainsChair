> **SPECIAL:** Before scoring, find and return up to 2 Incident.

## Rulings and open questions

- Cannot be played; the Passive works only if Su'Kal is promoted to Duty Officer by another effect.
- Returned Incidents no longer score their negative VP.
- Core Box printing of 2PER20, which To Boldly Go reprints (marked • there). The two are the same card and share code. Where the Core Box wording differs slightly, this spec keeps the To Boldly Go wording.
